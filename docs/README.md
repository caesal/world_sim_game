# Documentation Layout

The project documentation is split into two folders:

1. `docs/official`
   - Current user-facing universal documentation.
   - Versioned official game docs and change summaries.

2. `docs/unofficial`
   - Historical design notes, side docs, code-review instructions, probes, and working version logs.
   - The Codex architecture review source PDF lives here with its metadata.

For Ver0.3.6.c, this release update intentionally excludes `docs/official`.
Those files remain a separately requested user-facing documentation-freeze
series. The current code release keeps the Ver0.3.6.b four-tab
world-generation control UI and replaces its initial climate illustration with
the C2 continuous tendency field derived from automated calibration and
independent holdout evidence. The world-generation algorithms, existing
parameter interface, and save version remain unchanged.
The non-official release records are:

- `docs/unofficial/version_log.md`
- `docs/unofficial/ver0.3.6.c_side_doc.md`

The previous world-generation-control, static-geography, and named-plague
release records remain at:

- `docs/unofficial/ver0.3.6.b_side_doc.md`
- `docs/unofficial/ver0.3.6.a_side_doc.md`
- `docs/unofficial/ver0.3.6_side_doc.md`

The working version log is:

- `docs/unofficial/version_log.md`

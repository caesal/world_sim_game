# Documentation Layout

The project documentation is split into two folders:

1. `docs/official`
   - Current user-facing universal documentation.
   - Versioned official game docs and change summaries.

2. `docs/unofficial`
   - Historical design notes, side docs, code-review instructions, probes, and working version logs.
   - The Codex architecture review source PDF lives here with its metadata.

For Ver0.3.6, this release update intentionally excludes `docs/official`.
Those files remain a separately requested user-facing documentation-freeze
series. The current code release replaces the plague model, adds save-version-19
plague persistence and clean old-save rejection, adds linked outbreak
probability controls, and reorganizes the Plague panel into Live, Impact, and
History views. Deterministic model/presentation probes, bounded stress and
matched performance checks, targeted GUI validation, flicker checks, and fresh
Rule39 evidence cover this source stack.

- `docs/unofficial/version_log.md`
- `docs/unofficial/ver0.3.6_side_doc.md`

The working version log is:

- `docs/unofficial/version_log.md`
